Dashboard de Análise de Vendas de Café ☕
Documentação técnica e resumo executivo do projeto desenvolvido no Microsoft Excel para controle de receitas, análise de categorias e desempenho por canais de distribuição.

📋 Sumário Executivo
Este projeto consiste em um dashboard analítico focado no monitoramento de vendas de café especial e comercial. A ferramenta centraliza dados de vendas, produtos e clientes para responder a perguntas estratégicas de negócios, auxiliando na tomada de decisão sobre volume de vendas, faturamento e participação por país e canal de distribuição.

📁 Estrutura do Arquivo Excel
O livro de trabalho é estruturado em 4 folhas estratégicas:

Dashboard: Painel visual e executivo com indicadores-chave (KPIs), gráficos dinâmicos e segmentadores de dados (slicers) para análise interativa.

Calculos: Folha técnica utilizada para estruturar as tabelas dinâmicas e fórmulas de apoio que alimentam os gráficos e visões do painel principal.

BD_Ventas: Base de dados transacional com o registro detalhado de cada venda realizada (data, produto, categoria, país de origem, canal e montantes).

BD_Productos: Catálogo de produtos com SKUs, variedades, preços unitários e níveis de estoque disponível.

📊 Perguntas de Negócio Respondidas
O dashboard foi estruturado para responder a três perguntas principais de gestão comercial:

Produtos por País: Quais produtos específicos apresentam maior volume de vendas em cada país de destino/origem?

Categorias por País: Qual é a distribuição das vendas entre as categorias de café (Grão inteiro, Café Moído, Cápsulas, Bebida pronta e Edição Especial) em cada região?

Canais de Distribuição: Como as vendas se dividem entre os canais de Comercialização (Cafetería / Tienda, E-commerce e Distribuidor B2B) por país?

🛠️ Tecnologias e Funções Utilizadas
